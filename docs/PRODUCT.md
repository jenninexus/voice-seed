# Voice Seed — product

**Public name:** Voice Seed  
**GitHub:** [`jenninexus/voice-seed`](https://github.com/jenninexus/voice-seed) — **public** (2026-09-03)

A small **register map**: which writing voice applies where. Clone users (especially
Agency) copy templates and keep prose in *their* agent files. This is not a résumé
editor, not Patreon, not a Discord bot.

## Clone pairing

Agency is the loft-character prose SSOT. Voice Seed is an **optional** index so a
new desk does not mix résumé voice, Patreon voice, and audit chatVoice.

**Not product dependencies:** studio network-admin tools, theme-kit internals, a
specific live Discord bot. Relative `{bot}/` paths are the runtime contract.

Studio packaging / store board lives in the local product-design hub (`/products` ·
`SEED-FAMILY.md`). Do not copy that plan into this repo.
