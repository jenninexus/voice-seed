# Plans — session handoff

This folder and [`docs/ROADMAP.md`](../docs/ROADMAP.md) are the session log.
`/jen/roadmap` reads the roadmap. **Do not recreate** `dev-log-sego.yaml` at the
repo root. A frozen copy lives only in gitignored `private/archive/` if you need
the 2026-07-16 notes.

| Path | Role |
|------|------|
| `_active/` | At most one carryover plan. Empty = no session carryover; use the roadmap. |
| `_completed/` | Finished session plans |

Keep plans **clone-safe**: no machine-absolute disks, emails, legal names, or vault paths.
Studio-only notes stay in gitignored `private/` or `*.local.md`.
